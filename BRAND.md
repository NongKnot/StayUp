# StayUp Brand

This is the public source of truth for how StayUp should sound, look, and
behave in copy. If Duck feels off, check here before adding more words.

## Identity

- **Name:** StayUp. One word. Capital S, capital U.
- **Domain:** `getstayup.app`
- **Bundle ID:** `app.getstayup`
- **Character:** **Duck**. Capital D. Not "the mascot", not "the bird".
- **Motto:** `Duck's up, all night baby.`

Duck is funny because Duck sounds like trouble while still being clean enough
for public copy. Let the reader hear the joke. Do not explain it in shipped UI.

Useful Duck words:

- `Duck up`
- `Good Duck`
- `What The Duck`
- `Ducking Auto`
- `Mac(Book) Mini`

## Voice

Duck is confident, direct, a little stupid, and weirdly serious about keeping
the Mac awake.

Good StayUp copy is:

- short
- local-first
- funny without getting mean
- bold without overclaiming
- clear enough for normal people

Avoid:

- corporate copy like "thank you for choosing"
- vague AI hype like "AI-powered"
- generic product words when Duck words work
- making claims about competitors that are not freshly verified
- unpublished operating plans, business notes, or internal notes

## Product Truth

StayUp is a Mac menu-bar Duck for keeping local work alive.

The honest pillars:

- **Manual:** user turns Duck on or off.
- **Auto:** trusted local Activity Sources prove work, Duck stays up, then Duck
  stands down after the grace period.
- **Helper:** battery plus lid closed is the hard case; the Helper is how Duck
  handles it.
- **Virtual display:** useful for remote GUI tools when there is no real screen
  to stream. Not magic. Screen-shaped nonsense.
- **Privacy:** no telemetry, no accounts, no analytics, no crash reporting.

Do not say virtual display alone solves battery plus closed-lid sleep. The
Helper owns that hard case.

## Visual Rules

Duck should look like StayUp Duck:

- tall white body
- huge goofy eyes
- small orange beak
- orange feet
- black sketch outline
- warm, clean, slightly absurd

Do not use a generic duck, realistic duck, bath duck, angry duck, or unrelated
mascot for official StayUp surfaces.

Marketing images should show an actual use:

- closed MacBook while walking
- docked/desk setup
- local work running while Duck watches
- walking Duck animation

Pretty atmosphere alone is not enough. Duck must do a job.

## Activity Sources

Activity Source copy should stay generic until a specific integration edge
requires a tool name.

Use:

- Activity Source
- source
- receipt
- heartbeat
- local work
- reported source
- observed source

Avoid pretending app-open always means real work. If the user wants app-open
behavior, call it a presence source and make that choice clear.

## Public Repo Rule

The public repo can contain product docs, contributor docs, source recipes, and
brand guidance.

Do not commit:

- unpublished operating plans
- private marketing notes
- competitive research dumps
- business strategy notes
- credentials or local account files
- private Claude/Codex scratch state

Duck can be stupid. Repo should not be.
